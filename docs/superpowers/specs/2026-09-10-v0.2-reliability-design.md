# Local Autonomous Dev Team v0.2 Reliability Design

## Goal

Extend the existing sequential MVP without replacing its execution path. A project reaches `COMPLETE` only after deterministic full regression and an independent Final QA role both pass; otherwise the Manager receives explicit corrective work.

## Incremental architecture

1. **Completion gate.** Add `RegressionRunner` for safe project-local test/build discovery and `FinalQAAgent` structured `PASS`/`FAIL`. The orchestrator invokes both when executable work has drained. Final QA findings become normal pending corrective tasks.
2. **Durability and observability.** Extend durable state with schema-compatible heartbeat, phase, event records, task diagnostics, model metadata, and amendments. Persist intent before external effects and reconcile interrupted tasks at resume.
3. **Context and memory.** Build deterministic bounded context from spec/amendments, summary, decisions, task history, relevant files, tests, reviewer feedback, and errors. State projections supply human-readable logs, a summary, and decision JSONL.
4. **Interfaces.** Add role model profiles, capability metadata for Designer, requirement amendments, a stdlib local dashboard, and dependency-aware scheduling without introducing a cloud service or concurrent model loading.

## Safety and stop conditions

All commands remain non-shell, workspace-bound, and policy-checked. `COMPLETE` requires no pending work, no blocked requirements, successful regression, and Final QA `PASS`. `PAUSED`/`STOPPED` remain explicit user states. A genuine missing dependency or repeated distinct non-progress strategies produces `BLOCKED` with a durable diagnosis.

## Testing

Tests first cover Final QA pass/fail correction, regression output persistence, interrupted state reconciliation, heartbeat/event persistence, dependency selection, bounded context retrieval, model profile fallback, amendments, and dashboard rendering/control handlers. A deterministic medium-complexity notes-project E2E exercises repair, pause/resume, checkpointing, Final QA, and completion.
