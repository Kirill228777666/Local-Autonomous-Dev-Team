# v0.2 Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make long autonomous runs observable, recoverable, and independently verified before completion.

**Architecture:** Preserve the existing runner and add small isolated services for regression, Final QA, durability/observability, context, profiles, and dashboard delivery. All external side effects remain behind existing workspace tools and provider interfaces.

**Tech Stack:** Python 3.11+, standard library, pytest, Ollama.

**Spec:** `docs/superpowers/specs/2026-09-10-v0.2-reliability-design.md`

## Global Constraints

- Preserve current CLI commands and existing configuration defaults.
- Default to sequential role calls and never require multiple GPU-loaded models.
- Persist state atomically under `.autodev/`; do not store model chain-of-thought.
- Test every behavior first and run the full existing suite before each checkpoint.
